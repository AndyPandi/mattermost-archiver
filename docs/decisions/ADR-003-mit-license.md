# ADR-003: MIT License

Date: 2026-11-14

Status: Accepted

## Context
The repository owner explicitly requested MIT licensing before public distribution.

## Decision
License project software and documentation under the standard MIT License, copyright 2026 AndyPandi. Preserve third-party rights and exclude any implication that exported conversations or attachments inherit this license.

## Alternatives
Leaving the repository without a license would not grant general reuse permission.

## Consequences
Reuse including commercial use is permitted under the notice-retention conditions, without warranty. This does not change repository visibility or data-sharing permissions.
